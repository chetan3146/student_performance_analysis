# Student Performance Analysis

## About the Project
A beginner-friendly data analysis project using Python,
NumPy, and pandas to analyze student marks.

## Features
- Calculate total and average marks
- Check pass and fail results
- Find the class topper
- Calculate subject-wise averages
- Filter students with an average above 75
- Generate a class performance summary

## Technologies Used
- Python
- NumPy
- pandas

## Installation

Install the required libraries:

pip install numpy pandas

## How to Run

Run the following command in your terminal:

python student_performance.py

## Learning Outcomes
- NumPy arrays and numerical operations
- pandas DataFrames and filtering
- Conditional logic
- Basic data analysis
